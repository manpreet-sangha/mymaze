# 🎨 MyMaze - Interactive Maze Creator

Custom mazes for fun and enjoyment! Created with love for Yuvraj. ❤️

## 🌟 Features

### Editor Mode
- **🧱 Wall Drawing** - Draw walls to create obstacles (required for publishing)
- **🟡 Path Drawing** - Draw a solution path from Start to End
- **🟢 Start Point** - Customizable start icon (click to change)
- **🔵 End Point** - Customizable end icon (click to change)
- **🧹 Eraser** - Remove walls, paths, stamps, or points
- **🎨 Color Picker** - Choose custom colors with preset options
- **📏 Brush Size** - Adjustable size (2-10)

### 📢 Publishing System
- Save mazes with custom names
- Mazes stored in browser localStorage
- Gallery view of all published mazes
- Preview images automatically generated

### 🎮 Play Mode
- **Find Your Own Path** - Players navigate without seeing the creator's solution
- **Wall Blocking** - Player cannot pass through walls (stays at last valid position)
- **Visual Trail** - Glowing green trail shows player's path
- **Win Detection** - Celebrates when player reaches the end
- **↩️ Undo / ↪️ Redo** - Go back or forward in your trail (saves every 20 points)
- **🔄 Reset** - Start over from the beginning

## 🚀 How to Use

1. Open `maze-creator-v2.html` in a web browser
2. **Create a maze:**
   - Click Start/End icons to customize them
   - Draw walls to create obstacles
   - Draw a path connecting Start to End
   - Add stamps for decoration
3. Click **📢 Publish** when ready
4. Play your maze from the gallery!

## 🎮 How to Play

1. Move your mouse to the **START** point to begin
2. Navigate through the maze to reach the **END**
3. Avoid the walls - you can't pass through them!
4. Use **Undo/Redo** if you get stuck
5. Reach the end to win! 🎉

## 💻 Technical Details

- Built with HTML5 Canvas and vanilla JavaScript
- No external dependencies
- Touch support for mobile devices
- Data persisted in browser localStorage
- Animated stamps with CSS animations (bounce, wiggle, pulse)
